## What you'll need

<CardGrid>
	<Card title="A computer that stays on" icon="laptop">
		Your Mac, PC, or a home server. This is where your projects live and where the work actually happens — OpenShrimp is not a hosted service.
	</Card>
	<Card title="A Telegram account" icon="comment">
		Telegram is the entire interface. There's no separate app to install on your phone.
	</Card>
	<Card title="A Claude account" icon="star">
		A Claude Pro or Max subscription, or an Anthropic API key. You sign in once, from the bot.
	</Card>
</CardGrid>

Setting up is a download, a short detour through Telegram to create your bot, and a sign-in. [Start here](/getting-started/installation/).

## Features

<CardGrid stagger>
	<Card title="It asks before it changes anything" icon="approve-check-circle">
		Every file edit and every command comes to you as a button in the chat: allow once, allow for this session, or deny. Reading files inside your project is automatic; nothing outside it happens without you. See [tool approval](/guides/tool-approval/).
	</Card>
	<Card title="One bot, all your projects" icon="open-book">
		Switch between projects with `/context`. Each one remembers its own folder, model, permissions, and conversation history.
	</Card>
	<Card title="Run it in a sandbox" icon="seti:lock">
		Put the agent in a virtual machine, where it can't reach the rest of your computer. Inside the box, you can safely let it do anything. See [sandboxing](/guides/vm-sandbox/).
	</Card>
	<Card title="Your choice of model" icon="puzzle">
		Claude out of the box, or point it at OpenAI, Anthropic, and Google models through [OpenCode](/guides/backends/) — for everything, or just for one project.
	</Card>
	<Card title="It can use a browser" icon="laptop">
		Give the sandbox a screen and Claude can click, type, and browse the web to finish a task. You can watch it happen live from your phone. See [computer use](/guides/computer-use/).
	</Card>
	<Card title="Work while you're asleep" icon="seti:clock">
		Ask for something to happen every morning, or every Monday, in plain language. Claude runs it on schedule and reports back in the chat. See [scheduled tasks](/guides/scheduled-tasks/).
	</Card>
	<Card title="Review changes properly" icon="rocket">
		Diffs, terminal output, a live screen, and rendered markdown all open right inside Telegram, so you're not reading code in a chat bubble. See [Mini Apps](/guides/mini-apps/).
	</Card>
</CardGrid>
